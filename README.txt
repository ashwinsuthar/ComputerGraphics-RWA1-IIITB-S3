Ashwin Suthar MT2025024- 25/Sep/2026 updated- Procedural Modeling of Buildings RWA1 - CGA Shape WebGL Demo
====================

This standalone WebGL project based on my Overleaf report.

Run:
1. Extract the ZIP.
2. Open index.html in a modern browser with WebGL enabled.
3. If local-file restrictions interfere, run `python -m http.server 8000` in this
   folder and open http://localhost:8000.

Controls:
- Drag to orbit; scroll to zoom.
- Change building type, floor count, footprint dimensions and stochastic seed.
- Toggle simplified occlusion-aware opening suppression, snap-line alignment,
  roof geometry, and scope guides.

Reference scope:
This compact visual example is inspired by CGA Shape (Müller et al., 2006). It is
not the original CityEngine implementation and does not implement the complete
CGA language, exact spatial intersection queries, GIS import, or production-grade
topology.
